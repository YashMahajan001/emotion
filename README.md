# Emotion Detector

An AI-based web application developed using Python, Flask, and the IBM Watson Natural Language Processing (NLP) library.

## Project Description
This project detects emotions from user input text. It leverages Watson NLP Emotion Predict model to extract emotional scores for anger, disgust, fear, joy, and sadness, identifying the dominant emotion. The backend is deployed with Flask, and includes structured package design, unit testing, error handling for blank/invalid queries, and code compliance verified via static code analysis (pylint).
